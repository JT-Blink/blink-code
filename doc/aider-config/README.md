# Aider 配置文件备份

此目录包含 Aider AI 编程助手的配置文件备份。

## 文件说明

### 1. `.aider.conf.yml`
Aider 的主配置文件：
- **模型配置**: 指定默认使用模型（当前已注释，通过命令行指定）
- **上下文限制**: 设置聊天历史 tokens 限制为 50K
- **缓存配置**: 启用提示缓存提高性能
- **基本设置**: 禁用自动提交，启用流式输出

### 2. `.aider.model.settings.yml`
自定义模型设置文件：
- **主模型配置**: 为每个模型设置编辑格式、弱模型等
- **弱模型**: 统一使用 `openai/glm-4.6` 作为弱模型，用于生成提交消息等简单任务
- **编辑格式**: 所有模型使用 `diff` 格式进行代码编辑
- **高级功能**: 启用仓库地图、思考模式等

### 3. `.aider.model.metadata.json`
模型元数据文件：
- **上下文窗口**: 定义每个模型的最大输入/输出 tokens
- **成本信息**: 输入/输出价格（元/百万 tokens）
- **功能支持**: 函数调用、工具选择、缓存等能力

## 使用方法

1. 将这些文件复制到项目根目录
2. 根据需要修改 API 配置（环境变量或命令行）
3. 启动 Aider：`aider --model openai/360-qwen3-coder-480b-a35b`

## 环境变量

- `AIDER_MODEL`: 设置默认模型
- `AIDER_MODEL_SETTINGS_FILE`: 指定模型设置文件路径
- `AIDER_MODEL_METADATA_FILE`: 指定模型元数据文件路径
