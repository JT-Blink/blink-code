## 核心功能依赖

### ConfigArgParse
- **用途**: 增强的命令行参数解析，支持从配置文件、环境变量和命令行读取配置
- **关键特性**: 
  - 支持多种配置源（配置文件、环境变量、命令行）
  - 自动生成配置文件模板
  - 比标准 argparse 更灵活

### Rich
- **用途**: 在终端中提供丰富的文本格式和美化输出
- **关键特性**:
  - 彩色输出和格式化
  - 表格展示
  - 进度条
  - 代码语法高亮显示

### JSONSchema
- **用途**: 验证 JSON 数据结构
- **关键特性**: 
  - 确保数据结构符合预定义的模式
  - 在 AI 模型输入/输出验证中尤为重要

### Prompt_toolkit
- **用途**: 构建交互式命令行界面
- **关键特性**:
  - 自动补全
  - 语法高亮
  - 历史记录
  - 多行编辑

## AI 模型交互

### LiteLLM
- **用途**: 统一接口连接多种 LLM 模型
- **关键特性**:
  - 支持 OpenAI、Anthropic、Google、Azure 等多种 AI 提供商
  - 提供统一的 API 接口
  - 处理请求限速、错误重试等问题

### OpenAI
- **用途**: 与 OpenAI API 交互
- **关键特性**:
  - 支持 GPT 系列模型调用
  - 处理流式响应
  - 管理上下文和对话

### Google Generative AI
- **用途**: 与 Google 的 AI 模型交互
- **关键特性**:
  - 支持 PaLM、Gemini 等 Google 模型
  - 处理文本和图像输入
  - 生成文本响应

### Tiktoken
- **用途**: OpenAI 的令牌计数器
- **关键特性**:
  - 准确计算不同模型的令牌使用量
  - 优化输入以避免超出令牌限制

### Tokenizers
- **用途**: 处理文本标记化
- **关键特性**:
  - 将文本分割成令牌
  - 支持多种标记化策略
  - Hugging Face 生态系统的组件

### Llama-index-embeddings-huggingface
- **用途**: 使用 Hugging Face 模型进行文本嵌入
- **关键特性**:
  - 生成文本的向量表示
  - 支持语义搜索
  - 与 Llama Index 生态系统集成

## 代码分析与处理

### Grep-ast
- **用途**: 使用 AST 分析进行代码搜索
- **关键特性**: 
  - 基于抽象语法树的代码搜索
  - 比普通文本搜索更准确地理解代码结构

### Pathspec
- **用途**: 处理 gitignore 样式的路径模式匹配
- **关键特性**:
  - 匹配文件路径
  - 排除不需要处理的文件

### Diff-match-patch
- **用途**: 文本比较和补丁生成
- **关键特性**:
  - 生成文本差异
  - 合并更改
  - 处理冲突解决

### Tree-sitter-language-pack
- **用途**: 用于代码解析的树状语法分析库
- **关键特性**:
  - 增量解析
  - 多种编程语言支持
  - 用于代码高亮、导航和分析

### Flake8
- **用途**: Python 代码风格检查
- **关键特性**:
  - 检查 PEP 8 风格规范
  - 检测潜在的编程错误
  - 支持插件扩展

## 文件操作与存储

## 依赖版本约束说明

项目使用了一些特定版本约束来确保兼容性：

- **NetworkX < 3.5**: 限制版本以确保与 Python 3.10 兼容
- **SciPy < 1.16**: 1.16+ 版本需要 Python 3.11+
- **importlib-metadata < 8.0.0**: 避免 GitHub Release action 中的 "KeyError: 'home-page'" 错误
- **numpy < 2**: 确保与 sentence-transformers 兼容

这些约束在 `requirements/common-constraints.txt` 文件中进一步详细定义，确保所有子依赖版本之间的兼容性。
